<command-instruction>

あなたは二次創作の土台づくりを手伝います。原作の資料を `.novel/canon/` に整え、毎話の執筆資料として使える形にします。

## 前に確かめること

1. `novel_status(detailed: true)` でプロジェクトができているか確かめる（無ければ `/novel-init` で `sourceWork` を渡して作成してもらう）
2. `.novel/config.json` に `sourceWork` が無ければ、原作名を聞いて `"sourceWork": "原作名"` を足し、`.novel/canon/overview.md`・`timeline.md`・`setting.md` を作る

## いちばん大事な決まり

**原作の事実を記憶で埋めないこと。**
- 書き手に聞くか、原作で確かめてもらった内容を書き、出どころ（巻・話数など）を添える
- 記憶から仮出しした項目には必ず「（要確認）」を付け、書き手に確認してもらう
- 原作の文章・台詞・歌詞を写さない。出来事と設定は自分の言葉でまとめ、口調は特徴として書く

## 進めかた

### 一、スキルを読み込む
`novel-fanfic` skill を読み込みます。

### 二、土台を決める（`Question` ツール、1回4問まで）
1. **基準にする媒体と範囲**（原作小説／漫画／アニメ／ゲーム、どこまで踏まえるか）
2. **作品の形**（原作沿い／再構成／IF／前日談・後日談／日常スピンオフ／オリジナル主人公／転生・憑依／クロスオーバー）
3. **主人公と分岐点**（原作キャラかオリ主か、どの時点から分かれるか）
4. **変えること（1〜2点）と、この作品でしか読めない楽しさ**
5. **想定する読者**（原作既読前提／未読でも読める）と **投稿先**

### 三、権利と規約の確認
公開予定があるなら、`novel-fanfic` skill の「権利と、投稿先の決まり」に沿って、原作権利者のガイドラインと投稿先規約（掲載可否・必須タグ・年齢区分・生成 AI 表示）を書き手に確かめてもらい、確認日と内容を `canon/overview.md` に残します。

### 四、資料を書く

| ファイル | 書くこと |
|---|---|
| `.novel/canon/overview.md` | 基準の範囲、作品の形、分岐点、変えないこと・変えること、投稿先と確認事項 |
| `.novel/canon/timeline.md` | 分岐点より前の出来事、分岐点、分岐点より後の原作の出来事とこの作品での扱い（連鎖） |
| `.novel/canon/setting.md` | この作品で使う原作の設定（多い場合は `.novel/canon/setting/{項目}.md` に分割） |
| `.novel/canon/characters/{名前}.md` | 序盤に出る原作キャラを一人ずつ。**必ず `## ことばづかい` と `### 相手ごとの呼び方` の表を含める** |
| `.novel/glossary.md` | 原作の固有名詞・技名の表記と、まちがえやすい「使わない表記」 |

### 五、次へ案内する
整えた資料と「（要確認）」の残件をまとめ、`/novel-concept`（企画書）へ案内します。

## 約束

- 原作の事実を記憶で断定しない
- 権利や投稿先の規約を「大丈夫」と言い切らず、書き手に最新案内を確かめてもらう
- 日本語で答える
