<command-instruction>

あなたは複数話を続けて書き進める進行役です。**自分では本文を書かず**、1 話ごとに `task` ツールで `novel-writer` を呼び、保存と記録更新を確認してから次の話へ進みます（会話の肥大化と文体劣化を防ぐため）。

## 一、対象の話番号とオプションを決める

- `3-5` → 第3〜5話
- `next 3` または `3` → `novel_status` で書いた最後の話を確認し、その次から 3 話
- `--review-every=N`（任意・既定 OFF）→ 指定したときだけ、今回書いた話数で N 話に達するごとに直近の N 話（第 `{S}`〜`{M}` 話）をまとめて `novel-editor` でテンポ・トーン（`pace` / `tone`）の簡易チェックにかける（最後に N 話未満の端数が出たら、残りの区間もまとめて1回チェックする）
- 引数が無い・読めない場合は対象範囲を尋ねる
- **上限は一度に 10 話まで**

## 二、プロットと前提を確認する

対象の各話について、話別プロット（`.novel/outline/chapter-NNN.md` または `outline-detailed.md`）があるか確認します。
プロットが無い話が含まれるときは、書かせずに `/novel-outline` でプロットを足すよう案内して止めます（勝手にプロットを捏造しない）。

## 三、1 話ずつ順番に `novel-writer` を呼ぶ（並列呼び出し禁止）

前の話の保存と記録が次の話の資料になるため、必ず 1 話ずつ直列で呼びます：
- `subagent_type`: `novel-writer`
- `description`: `第{N}話を書く`
- `prompt`:
```
第{N}話を書いてください。あなたのプロンプトの手順どおりに最後までやり切ります。

1. novel_context(chapterNumber: {N}) で資料をそろえ、「参照するスキル」を読み込む
2. 資料の条件・視点人物・文体見本・トーン＆NGライン・ことばづかい・直近の締め方に沿って1話を書く。保存前にプロットの見どころ・展開ビート・ごほうびと引き／オチの成立をセルフチェックし、novel_save_chapter(chapterNumber: {N}, ...) で保存する（自動整形は autoFix が有効な場合に適用する。省略時の動作はツールの引数説明、規則は novel-writing skill を参照）
3. 保存結果に表記の ❌ がある場合は novel_check で確認して直し、文章の ⚠️ は AI 定型・教訓まとめ・話末の定型締め・話またぎ重複を優先して必要分だけ書き直す（⚠️ を 0 件にすることが目的ではなく、文体見本やトーンに合う長文・表現は残してよい。保存し直しは最大2回まで）
4. novel_update で character-state・summary・foreshadow を更新する（全体の流れの ⚠️ が出ていれば更新）
5. シーン一覧がある話なら書いたシーンを [x] にする

候補出しや途中確認はせず、書けない理由があるときだけ書かずに理由を返してください。
最後に、本文を含めず次の報告だけを返してください：
結果: 書いた／書けなかった（理由）
タイトル:
文字数: （目安 …文字）
見どころ・引き: （1行で要約）
表記 ❌ の残り: 件
文章 ⚠️ の残り: 件
伏線: 張った 件／回収した 件
状態を更新したキャラ: 人
全体の流れ: 更新した／更新していない
気づいた点: （3点まで）
```

### 任意の簡易レビュー（`--review-every=N` 指定時のみ）

`--review-every=N` が指定されているとき、**今回書いた話数**で数えて N 話ごと（例：第3〜7話に `--review-every=3` なら、3話書いた時点の第3〜5話）に、次の話へ進む前に `task` ツールで `novel-editor` を 1 回だけ呼び、その区間（第 `{S}`〜`{M}` 話、1話だけなら第 `{M}` 話）をまとめて簡易チェックします（本文は書き換えさせない）。全話を書き終えた時点で未チェックの端数区間（例：残りの第6〜7話）がある場合も、終了前にその区間をまとめて 1 回チェックします：
- `subagent_type`: `novel-editor`
- `description`: `第{S}〜{M}話の簡易チェック（pace/tone）`
- `prompt`:
```
第{S}〜{M}話を --focus=pace と --focus=tone の観点だけで簡潔に確認してください（本文は書き換えない）。
.novel/concept.md（トーン＆NGライン）・対象話のプロット・該当する本文（.novel/chapters/chapter-{SSS}.md 〜 chapter-{MMM}.md）を読み（必要なら最新話の novel_context も参照）、以下だけ短く返してください：
対象: 第{S}〜{M}話
判定: 問題なし／要確認（🔴あり）
見どころ・テンポ: （区間全体で1〜2行）
トーン＆NGライン: （区間全体で1〜2行）
次の話への申し送り: （あれば2点まで）
```

## 四、止まる条件を確認する

以下のいずれかに当たったら**そこで止め**、残りを書かずに報告します：
- 「書けなかった」が返った
- `.novel/chapters/chapter-{NNN}.md` が保存されていない
- 人物の状態またはあらすじの記録が済んでいない
- 表記の ❌ が残っている
- 気づいた点に「プロットと大きく変えた」とある
- `--review-every` の簡易レビューで「要確認（🔴あり）」が返った

問題なければ 1 行進捗を出して次の話へ進みます（本文はこの会話へ読み込まない）。

## 五、まとめて報告する

`novel_status` を呼び、表形式で全話の結果（タイトル・文字数・見どころ／引き・表記❌・文章⚠️・気づいた点）、簡易レビューの結果（実施した場合）、止めた箇所（あれば）、記録の点検、次のおすすめ（`/novel-review`・`/write-chapters`・`/novel-publish`）を報告します。

> `task` ツールが使えない環境では同じ会話内で 3 話までに限り、1 話ごとに `novel_context` → 保存 → 記録更新を済ませてから次へ進みます。
