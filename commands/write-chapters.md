<command-instruction>

あなたは複数話を続けて書き進める進行役です。**自分では本文を書かず**、1 話ごとに `task` ツールで `novel-writer` を呼び、保存と記録更新を確認してから次の話へ進みます（会話の肥大化と文体劣化を防ぐため）。

## 一、対象の話番号とオプションを決める

- `3-5` → 第3〜5話
- `next 3` または `3` → `novel_status` で書いた最後の話を確認し、その次から 3 話
- `--review-every=N`（任意・既定 OFF）→ 指定したときだけ、今回書いた話数で N 話に達するごとに直近の N 話（第 `{S}`〜`{M}` 話）をまとめて `novel-editor` でテンポ・トーン（`pace` / `tone`）の簡易チェックにかける（最後に N 話未満の端数が出たら、残りの区間もまとめて1回チェックする）
- `--revise`（任意・既定 OFF）→ 指定したときだけ、各話で「下書き保存 → `novel-editor` の講評 → 必要時のみ `novel-writer` で最大 1 回リライト → 確定稿で記録更新」を回す。主に序盤第 1〜3 話向けで、**一度の上限は 3 話まで**（4 話以上指定された場合は 3 話以内の分割を案内して止める）。`--review-every` と同時指定された場合は各話レビュー済みのため区間簡易チェックは行わない
- 引数が無い・読めない場合は対象範囲を尋ねる
- **通常時の上限は一度に 10 話まで**

## 二、プロットと前提を確認する

対象の各話について、話別プロット（`.novel/outline/chapter-NNN.md` または `outline-detailed.md`）があるか確認します。
プロットが無い話が含まれるときは、書かせずに `/novel-outline` でプロットを足すよう案内して止めます（勝手にプロットを捏造しない）。

## 三、1 話ずつ順番に書く（並列呼び出し禁止）

前の話の保存と記録が次の話の資料になるため、必ず 1 話ずつ直列で進めます。

### 通常モード（`--revise` なし）

- `subagent_type`: `novel-writer`
- `description`: `第{N}話を書く`
- `prompt`:
```
第{N}話を書いてください。あなたのプロンプトの手順と novel-writing skill（および novel_context が示すジャンルスキル）どおりに、資料取得・執筆・保存・点検・記録更新（character-state / summary / foreshadow、シーン一覧があれば [x] 更新）まで最後までやり切ります。

候補出しや途中確認はせず、書けない理由があるときだけ書かずに理由を返してください。
最後に、本文を含めず次の報告だけを返してください：
結果: 書いた／書けなかった（理由）
タイトル:
文字数: （目安 …文字）
見どころ・引き: （1行で要約）
表記 ❌ の残り: 件
文章 ⚠️ の残り: 件
伏線: 張った 件／回収した 件
状態を更新したキャラ: 人
全体の流れ: 更新した／更新していない
気づいた点: （3点まで）
```

### 推敲モード（`--revise` 指定時のみ・各話最大 1 回リライト）

1. **下書き執筆（`novel-writer`）**：
   - `subagent_type`: `novel-writer` / `description`: `第{N}話の下書きを書く`
   - 通常モードと同じ方針で資料取得・執筆・保存・機械点検（表記 ❌ 解消）まで行わせ、**記録更新（`novel_update` とシーン `[x]`）は確定稿の後に行うため実行しない**よう指示する。本文を含めず、結果・タイトル・文字数・見どころ／引き・表記 ❌／文章 ⚠️ の残り・気づいた点を返させる。
   - 「書けなかった」または保存失敗・表記 ❌ 残りの場合は、講評へ進まず四の停止条件で止める。
2. **編集者講評（`novel-editor`）**：
   - `subagent_type`: `novel-editor` / `description`: `第{N}話の推敲講評`
   - `prompt`:
```
第{N}話の下書きを novel-editing skill の5軸（特に見どころ・溜めとごほうび、キャラ立ち、トーン＆NGライン、つじつま）で短く講評してください（本文ファイルは書き換えない）。
対象話の novel_context・novel_check と .novel/chapters/chapter-{NNN}.md を読み、書き手の勢いや文体見本を無難に丸める細かい言い回し変更は求めず、以下で判定します：
- 「そのまま採用」：🔴 が無く、見どころ・溜めの大きな欠けも無い → このまま確定稿として、まず `novel_update(action: "prompt", content: "character-state-update", chapterNumber: {N})` と `novel_update(action: "prompt", content: "summary-update", chapterNumber: {N})` を取得して記録の決まりを確認したうえで、novel_update（character-state・summary・foreshadow、全体の流れの ⚠️ が出ていれば更新）とシーン一覧の [x] 更新まで済ませて報告を返す
- 「リライト推奨」：🔴 がある、または見どころ・溜めを大きく伸ばせる 🟡 がある → 記録更新はせず、直す点（🔴 はすべて、🟡 は最重要の最大 2 点まで。「何が起きているか／どう直すか」を箇条書き）だけを短く返す

報告形式（本文は含めない）：
判定: そのまま採用／リライト推奨
よい点: （1〜2点）
直す点: （リライト推奨時のみ。🔴全件＋最重要🟡最大2点）
記録更新: 済み（伏線・更新キャラ・全体の流れの要約）／保留（リライト後に実施）
```
3. **リライトと確定記録（`リライト推奨` のときのみ・最大 1 回）**：
   - `subagent_type`: `novel-writer` / `description`: `第{N}話を講評に沿って書き直す`
   - `novel-editor` の「よい点」「直す点」を渡し、**まず保存済みの `.novel/chapters/chapter-{NNN}.md` と `novel_context(chapterNumber: {N})` を読んでから**、よい点と文体の勢いを保ったまま指摘箇所を中心に手直しする（ゼロから全面的に書き直さない）よう指示する。手直し後に `novel_save_chapter` で保存・機械点検（❌解消）し、確定稿の内容で `novel_update`（`character-state`・`summary`・`foreshadow`）とシーン `[x]` を更新して通常モードと同じ報告形式で返させる。

### 任意の簡易レビュー（`--review-every=N` 指定かつ `--revise` なし時のみ）

`--review-every=N` が指定されているとき、**今回書いた話数**で数えて N 話ごと（例：第3〜7話に `--review-every=3` なら、3話書いた時点の第3〜5話）に、次の話へ進む前に `task` ツールで `novel-editor` を 1 回だけ呼び、その区間（第 `{S}`〜`{M}` 話、1話だけなら第 `{M}` 話）をまとめて簡易チェックします（本文は書き換えさせない）。全話を書き終えた時点で未チェックの端数区間（例：残りの第6〜7話）がある場合も、終了前にその区間をまとめて 1 回チェックします：
- `subagent_type`: `novel-editor`
- `description`: `第{S}〜{M}話の簡易チェック（pace/tone）`
- `prompt`:
```
第{S}〜{M}話を --focus=pace と --focus=tone の観点だけで簡潔に確認してください（本文は書き換えない）。
.novel/concept.md（トーン＆NGライン）・対象話のプロット・該当する本文（.novel/chapters/chapter-{SSS}.md 〜 chapter-{MMM}.md）を読み（必要なら最新話の novel_context も参照）、以下だけ短く返してください：
対象: 第{S}〜{M}話
判定: 問題なし／要確認（🔴あり）
見どころ・テンポ: （区間全体で1〜2行）
トーン＆NGライン: （区間全体で1〜2行）
次の話への申し送り: （あれば2点まで）
```

## 四、止まる条件を確認する

以下のいずれかに当たったら**そこで止め**、残りを書かずに報告します：
- 「書けなかった」が返った
- `.novel/chapters/chapter-{NNN}.md` が保存されていない
- 人物の状態またはあらすじの記録が済んでいない（`--revise` の推敲モードでは、下書き段階ではなく確定稿の後に判定する）
- 表記の ❌ が残っている
- 気づいた点に「プロットと大きく変えた」とある
- `--review-every` の簡易レビューで「要確認（🔴あり）」が返った

問題なければ 1 行進捗を出して次の話へ進みます（本文はこの会話へ読み込まない）。

## 五、まとめて報告する

`novel_status` を呼び、表形式で全話の結果（タイトル・文字数・見どころ／引き・表記❌・文章⚠️・気づいた点）、推敲（`--revise`）や簡易レビューの結果（実施した場合）、止めた箇所（あれば）、記録の点検、次のおすすめ（`/novel-review`・`/write-chapters`・`/novel-publish`）を報告します。

> `task` ツールが使えない環境では同じ会話内で 3 話までに限り、1 話ごとに `novel_context` → 保存 → 記録更新を済ませてから次へ進みます。
