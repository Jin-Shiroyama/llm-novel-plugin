# 人物名の照合と記録

## 背景と境界

fd42195・583946c で姓名の推測分割を調整したが、佐伯悠真・長谷川栞・林美智子の切れ目を文字数では決定できない。推測候補が状態と口調の照合にも流用され、別人の状態の適用や同一人物の二重記録が起きていた。

`core/character-names.ts` が人物索引の正本。シート選択、記録の名前解決、状態・ことばづかいの資料生成が同じ索引を使う。コアはハーネスに依存しない。

## 入力

| 入力 | 用途 |
|---|---|
| シートの拡張子を除いたファイル名 | 正式名。状態更新など一人への名前解決では完全一致が他の呼称に優先する |
| シートの「名前」欄 | 全体と、空白・中黒で明示された部分。引用外の対応済み丸括弧注記は途中も除外。引用・括弧外の `/`・`／` 以降は肩書き等の補足 |
| 呼称・別名・通称・愛称・あだ名の欄（`・ / ／` による既知ラベルの組み合わせも可） | 括弧・引用の外側の `、 , ， / ／` で区切る。候補内の空白・中黒は保持。末尾に連続する丸括弧注記だけを除外 |
| 当話のプロット・シーン、短編プロット | 出現判定の第一資料 |
| 前の話・節の末尾 | 出現判定の第二資料。未来の本文は使わない |
| state.json の名前と相手キー | 完全一致による同一人物の解決 |

字数・文字種による分割、括弧の読みからの候補生成はしない。呼称の雛形は候補にしない。呼称が無い人物は status で通知する。別名が不要なら正式名を呼称欄にも書く。

`name-fields.ts` が欄の解析の正本。項目全体を `「...」`（既存互換で `『...』` も可）で囲んだ場合は、外側だけを外して内部を一候補として保持する。`「ハル」、「春樹」` は二候補、`「A/B」` は一候補。独自のエスケープはない。未閉じ・不対応の括弧は削って連結せず、その項目を不採用にして status でファイル・行を通知する。

先頭の開き引用に対応する閉じ引用が項目末尾にある場合だけ、一組の引用として扱う。`「ハル」「春樹」` のように区切りなく並ぶ項目は結合せず、不採用と通知にする。末尾注記を外した後にも外側の装飾・引用を確認し、`「ハル」（愛称）`・`**ハル**（愛称）` は `ハル` とする。引用内部の括弧・区切りは保持する。

名前欄の `佐伯（さえき） 悠真（ゆうま）／主人公` は `佐伯 悠真`・`佐伯`・`悠真`。呼称欄の `栞（しおり）（読み）` は `栞`。読みを照合したい場合は独立した呼称として書く。

原作と作品側に同じ正式名のシートがある場合は同じ人物として手がかりを共有する。設定資料は双方を区別して掲載し、ことばづかいは従来どおり作品側のシートを優先する。

## 出現判定

長い手がかりを先に消費する。正式名「佐伯美咲」の中の「佐伯」から兄の資料を選ばない。1文字または複数人物の共通呼称の一致は弱い根拠とする。普通名詞との意味の区別はしない。

同じ表記の所有者は全員を候補にする。人物 A の正式名が人物 B の呼称と一致する場合も、文章中では A・B とも弱い候補になる。出現判定は一人への名前解決を呼び出さない。空の手がかりは無視し、文書ラベルの前後空白は照合時に統一する。

優先順は当話の強い一致、当話の弱い一致、前の節の強い一致、前の節の弱い一致、一覧・その他の概要。同順位では既存の文書順を保つ。シート・状態・口調に共通の順位を使い、設定シートの文字数は上位の枠から配分する。

任意の視点・登場人物指定がある場合は、視点人物、明示された登場人物をこの順序の前に置く。継承・検証・入力場所は [視点人物の指定](pov-context.md) を参照。

一致ゼロまたは検索文が空なら、全員の詳細へ戻さない。人物一覧と未特定の通知を出す。シート未登録の状態は記録名そのものを手がかりにする。

## 同一人物の解決と書き込み

1. 正式名の完全一致。
2. 明記された手がかりに一意に一致すれば正式名へ変換。
3. 複数候補なら更新バッチ全体を拒否し、正式名の候補を示す。
4. 一致しなければシート未登録の人物として入力名で記録し、そのことを知らせる。

`relationships` と `speech.addressTerms` の相手キーも解決する。呼び方の値は変更しない。同じ相手へ解決されるキーが異なる値を持つ場合は書き込みを拒否する。

既存記録は名前を解決してから節の順に差分を適用する。null による削除、一覧の追加・削除、出来事、変更時点を保持する。曖昧な旧記録は別人へ結合せず通知する。同じ節の旧記録で相手キーが衝突する場合は列挙順の最後を採用し、衝突を通知する。

読むだけではファイルを変更しない。更新時も対象の節だけを正規化し、他の節は元の記録を保持する。同じ節の複数差分は入力順に適用する。最終状態に変更が無ければ従来どおり書き込まない。

## 受け入れ条件

| 条件 | 期待 |
|---|---|
| 呼称・区切りのない長谷川栞を「栞」で検索 | 選ばれない。status に呼称未記入 |
| 名前欄「長谷川 栞」を「栞」で検索 | 選ばれる |
| 白瀬栞を「白い花」で検索 | 選ばれない |
| 栞と長谷川栞で別の節に状態を更新 | 一人分として最新状態・口調を生成 |
| 兄妹の共通呼称「佐伯」で更新 | 保存せず候補を通知 |
| 前の節の末尾だけに栞が出る | 当話の人物より低い順位で設定・口調・状態を掲載 |
| 旧記録の同一人物に null・一覧削除の差分 | 統合後にも削除が有効。読み込みだけではファイル不変 |

互換性確認では、旧版と新版で掲載人物が減った作品の呼称欄を補う。正式名を変更する場合は旧名を呼称に残す。同名の別人をファイル名だけで区別する機能はない。
