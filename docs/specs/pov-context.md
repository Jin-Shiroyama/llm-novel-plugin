# 視点人物と明示的な登場人物

代名詞だけのプロットでも語り手の設定・状態・口調を選べるようにする任意機能。姓名・主人公という役割・代名詞からは視点人物を推測しない。シーン分割も必須にしない。

## 入力

- `config.json` の `defaultPovCharacter`: 作品既定の一人。キャラ設計後に正式名で設定する。`novel_init` では生成しない。
- 話・節のプロット（短編は `outline-brief.md`）の `- **視点キャラ**：正式名`。
- シーンの `- **視点キャラ**：正式名`。
- 話・節・シーンの任意の `- **登場人物**：正式名、正式名`。項目分割は呼称欄と同じ共通パーサを使う。

「登場キャラと掛け合い」は自由文のまま出現検索に使い、厳格な参照として検証しない。`narrativePerspective` は語り方であって人物指定ではない。

正式名を推奨し、一意に解決できる呼称も読み取り時は受理する。呼称経由では正式名への更新を案内する。未登録・曖昧な指定は人物を自動作成せず通知する。同じ範囲に視点欄が複数あれば不正とする。読むだけではファイルを書き換えない。

LF・CRLF のどちらでも同じ欄を読み取り、出現検索からも除外する。設定値の前後空白は予約値の判定前に除く。コードフェンス内の欄や見出しは指定・検証対象にしない。閉じフェンスは開始と同じ文字で、開始以上の長さがあり、後ろに空白以外の文字がない行に限る。

## 継承

シーン → 話・節 → 作品既定の順に解決する。

| 値 | 動作 |
|---|---|
| 欄の省略・空欄・`[…]` の雛形 | 上位を継承 |
| 有効な人物名 | その人物を採用 |
| 前後空白を除いた `なし` | その範囲で継承を停止 |
| 未登録・曖昧・複数名・`（なし）`・`-` 等の不正な明示値 | 未解決と通知。上位で置き換えない |

`なし` は話・シーンで使う予約値。作品全体に既定を設けない場合は設定項目を省略する。`なし` は登場人物の資料を除外する意味ではない。登場人物欄は候補の追加指定で、文章中の出現検索を制限しない。

`sceneId` 未指定では対象話の各シーンを個別に継承解決し、全視点人物を重複除去して集める。全シーンが上書き・継承停止していれば作品既定の人物を無条件には加えない。シーンがなければ話・節の指定を解決する。`sceneId` 指定時は対象シーンだけを解決し、存在しないシーンは未解決と通知する。資料にはシーンと視点の対応を掲載する。

登場人物は話・節と対象シーンの指定の和集合。話全体の場合は全シーン分を集める。専用欄は文章中の出現検索から外し、継承で無効になった指定を検索で再採用しない。

## 資料の優先度

有効な視点人物 → 明示された登場人物 → 当話の強い一致・弱い一致 → 前の節の強い一致・弱い一致 → 人物一覧・その他の概要。

設定・状態・口調で共通の順位を使う。同順位は既存の順序を保つ。既存の文字数上限を維持し、資料の省略では人物名を表示する。全員の詳細へのフォールバックはしない。

## 運用と検証対象

`/novel-characters`・novel-planner が、視点人物も決まった段階で任意設定を案内する。未定のままでもプロット・執筆へ進める。指定と改名後の参照は `novel_status` で確認する。

検証対象は次に固定し、分割・統合の両方がある場合も両方を検証する。

1. `config.json` の `defaultPovCharacter`
2. `outline-detailed.md` と `outline/*.md`
3. 短編時の `outline-brief.md`
4. `scenes.md` と `scenes/*.md`

実際の資料生成では従来どおり分割ファイルを優先する。旧名が呼称に残る改名は解決しつつ更新を案内し、解決できない改名・削除は警告する。
